# AI Agent Project

A multi-agent AI system built with Python.

## Project Structure

```
ai-agent-project/
├── agents/           # Agent definitions
│   ├── research_agent.py
│   ├── writer_agent.py
│   └── manager_agent.py
├── tools/            # Custom tools
│   ├── web_search.py
│   └── file_saver.py
├── memory/           # Memory and storage logic
├── ui/               # Streamlit frontend
├── tests/            # Test files
├── notebooks/        # Jupyter/Colab experiments
├── .env.example      # API key template
├── requirements.txt  # Python dependencies
└── README.md
```

## Setup

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your API keys
3. Install dependencies: `pip install -r requirements.txt`
4. Start building!
